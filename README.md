# AI Vibe Coding Landing Page

Дайын 1 беттік курс сататын сайт.

## Іске қосу
1. Папканы ашыңыз
2. `index.html` файлын браузерде ашыңыз

## Vercel-ге шығару
1. GitHub-қа осы папканы жүктеңіз
2. vercel.com → New Project
3. Репозиторийді таңдаңыз
4. Deploy басыңыз
